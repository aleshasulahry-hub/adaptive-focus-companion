# Adaptive Focus Companion

Adaptive Focus Companion is a multi-page web-based productivity and wellness tool designed to help users manage mental energy during long screen-based work or study sessions. The website begins with a quick energy check-in where users rate their focus, stress, and alertness levels. Based on that input, the app recommends a focus session length, provides supportive suggestions, and guides the user into a session dashboard with a timer. The project also includes a basic insights page that displays saved session history and simple patterns using browser storage. It is built as a front-end website using HTML, CSS, and JavaScript.

## Purpose

This project exists to support students, remote workers, and other people who spend long periods working on screens and may struggle with fatigue, stress, or inconsistent concentration. Many productivity tools focus only on managing time, but this project approaches the issue as one of energy management. The goal is to provide a more supportive and realistic way for users to work by helping them check in with their current mental state, adjust session length, and reflect on patterns over time. This website is intended for users who want a simple, calming tool that encourages sustainable focus instead of burnout.

## Tools and Technologies

- **Visual Studio Code** - I used Visual Studio Code to write and organize my project files because it provides a simple workflow for front-end development and works well with HTML, CSS, and JavaScript.
- **HTML** - I used HTML to build the structure of the website and create separate pages for the check-in, session dashboard, insights, and about sections.
- **CSS** - I used CSS to style the layout, colors, typography, dark and light mode, and the overall visual design of the project.
- **JavaScript** - I used JavaScript to add interactivity such as the adaptive timer, connected page behavior, theme toggle, minimal distraction mode, and local storage for saving session data.
- **Local Storage** - I used browser local storage to save session information and theme preferences so the website can carry data between pages and show basic insight history.
- **GitHub** - I used GitHub to store my code, manage version control, and keep track of changes to the project.
- **GitHub Pages** - I used GitHub Pages to deploy and host the live version of the website so it can be accessed through a public link.
- **ChatGPT** - I used ChatGPT as an AI assistant to help with debugging, improving code structure, refining design ideas, and planning the features of the site.
