# Adaptive Focus Companion

Adaptive Focus Companion is a web-based productivity and wellness tool designed to help people manage their mental energy during long screen-based work or study sessions. The project allows users to complete a quick check-in by rating their focus, stress, and alertness levels, then uses that input to suggest a focus session length and start a timer. It is a simple website prototype built for Project 01 using HTML, CSS, and JavaScript.

## Purpose

This project exists to support students and other people who spend long periods working on screens and may struggle with fatigue, stress, or inconsistent focus. Instead of treating productivity only as a time-management issue, this project approaches it as an energy-management issue. The website is intended for students, remote workers, and other users who want a simple and supportive tool to help them work in a more balanced and sustainable way.
