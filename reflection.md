# Reflection

## Decisions
One of the most important decisions I made during this project was to focus on improving existing features instead of constantly adding new ones. Initially, I considered adding more tools like quote generators or additional wellness features. However, I realized that expanding the scope too much would make the project feel scattered and less polished.

Instead, I chose to focus on making the core idea stronger. I improved the check-in system, session recommendations, and insights tracking so that they felt more connected. I also prioritized improving the user interface, including spacing, layout, and consistency across pages. This decision helped the project feel more like a complete product rather than a collection of ideas.


## What worked
One of the things that worked well was the overall concept of adapting focus sessions based on the user’s mental state. The check-in system combined with session recommendations creates a more personalized experience compared to a standard timer.

Another aspect that worked well was the multi-page structure. Separating the app into Check-In, Dashboard, Insights, and About made the project easier to navigate and understand. It also helped organize the functionality clearly.

I am also satisfied with the visual design. The use of typography, spacing, and the dark/light mode helped make the site feel more intentional and polished compared to earlier versions.


## What I would do differently
If I were to start over, I would spend more time planning the structure and logic before coding. At times, I ran into issues where features (like sliders or session updates) did not behave correctly, and I had to go back and debug them later.

I would also test the site more frequently on different devices earlier in the process. Some layout issues only became noticeable later, which required additional adjustments.

Another thing I would change is organizing my JavaScript more clearly from the beginning. As the project grew, it became harder to manage everything in one script file.


## What I learned
This project helped me understand that building a good web application is not just about adding features, but about making those features meaningful and usable.

I learned how to:
- Use localStorage to persist user data across pages
- Connect multiple pages into one cohesive experience
- Debug issues in JavaScript and improve functionality
- Design with consistency in mind (layout, fonts, colors)
- Think more critically about user experience

I also learned that iteration is an important part of development. My Project 01 version was functional, but Project 02 pushed me to refine and improve it into something more complete.

Overall, this project helped me grow both technically and in how I think about designing and building for users.
