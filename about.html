ABOUT THE PROJECT

What is Adaptive Focus Companion?

Adaptive Focus Companion is a web-based tool that helps users manage mental energy during long study or work sessions. It begins with a quick check-in using focus, stress, and alertness levels, then recommends a session length and provides supportive suggestions.

Why it exists

Many students and screen-based workers struggle with burnout, fatigue, and inconsistent focus. This project approaches productivity as an energy-management challenge rather than only a time-management problem.

Current features

  • Quick energy check-in
  • Adaptive recommended session length
  • Focus timer
  • Dark and light mode
  • Saved session history using local storage
  • Basic insights and recommendations
